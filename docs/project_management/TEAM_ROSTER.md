## 三、角色职责与禁止行为

### 3.1 项目经理（PM）— 协调者

**职责**: 协调团队、任务分配、进度追踪、风险管理
**禁止**: 做技术决策、修改代码、修改需求、评判技术方案
**当前积分目标**: 流程合规协调 +2/次，团队稳定性

### 3.2 产品经理 — 需求者

**职责**: 定义需求范围、业务优先级、验收标准
**禁止**: 设计技术方案、定义API接口、写实现代码、做技术选型
**决策权**: 需求范围、验收标准、发布时间
**回调**: 技术方案 → 架构师

### 3.3 架构师 — 决策者

**职责**: 技术架构设计、技术选型、API契约定义、数据模型设计
**禁止**: 写生产代码、写测试代码、修改已有代码、定义实现细节
**决策权**: 技术栈、API接口定义、数据模型、架构风格
**回调**: 具体实现 → 开发者

### 3.4 开发者 — 实现者

**职责**: 按ADR实现代码、Bug修复、代码重构
**禁止**: 做技术选型、修改API契约、修改架构文档
**决策权**: 函数实现方式、变量命名、代码组织结构
**前置依赖**: 必须有 ADR + API 契约才能开始实现

### 3.5 测试员 — 验证者

**职责**: 测试用例设计、测试执行、Bug报告、覆盖率分析
**禁止**: 修改生产代码、修改需求文档、修改架构文档
**决策权**: 测试用例设计、测试范围、通过/失败判断

### 3.6 代码审查员 — 判别器

**职责**: 代码质量审查、架构合规检查、安全审计
**禁止**: 修改任何文件（只读）
**审查强度**: Normal（开发流水线）

### 3.7 Bug猎人 — 判别器

**职责**: 激进代码审查、边界探测、安全漏洞发现
**禁止**: 修改任何文件（只读）
**审查强度**: Aggressive（Bug修复流水线）

### 3.8 文档管理员 — 维护者

**职责**: 编写和维护技术文档
**禁止**: 编辑代码文件
**决策权**: 文档结构、文档格式
