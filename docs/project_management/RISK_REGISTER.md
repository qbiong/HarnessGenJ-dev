## 风险详情

### R01: tiktoken 编译安装失败

**识别时间**: 2026-04-12
**发现者**: PM
**影响模块**: `llm/token_counter.py`
**影响说明**: tiktoken 需要编译原生扩展，Windows 环境下可能缺少编译工具链。

**影响评估**:
- 影响: 中（token 计数不精确但不影响核心功能）
- 概率: 中（Windows 上编译问题常见）
- 风险等级: 🟡 中

**应对策略**:
- ✅ **已实施降级**: token_counter.py 已实现简单字符计数降级方案
- 📋 **备选方案**: 预编译 wheel 或改用其他 token 计数库
- 📋 **长期方案**: 确保 CI/CD 环境有编译工具链

**责任人**: 开发者（dev_1）

---

### R02: LLM API 费用过高

**识别时间**: 2026-04-12
**发现者**: PM
**影响模块**: `llm/gateway.py`, Agent 循环
**影响说明**: 开发/测试过程中大量调用 LLM API 可能导致费用失控。

**影响评估**:
- 影响: 高（直接影响项目成本）
- 概率: 中（取决于使用频率）
- 风险等级: 🟠 高

**应对策略**:
- 📋 **Token 预算控制**: 在 config.py 中添加 max_monthly_cost 配置
- 📋 **Mock 优先**: 开发阶段优先使用 Mock LLM 响应
- 📋 **模型降级策略**: 日常开发使用 Haiku，仅关键任务用 Sonnet/Opus
- 📋 **使用量监控**: 实现 UsageReport 告警机制

**责任人**: PM（pm_1）+ 架构师（arch_1）

### R03: Textual 兼容性问题

**识别时间**: 2026-04-12
**发现者**: PM
**影响模块**: `tui/app.py`
**影响说明**: Textual 可能对终端类型或 Python 版本有特定要求。

**影响评估**:
- 影响: 中（TUI 不可用但 CLI 仍可用）
- 概率: 低（Textual 成熟度较高）

**应对策略**:
- 📋 **备选方案**: prompt_toolkit 作为轻量备选
- 📋 **渐进开发**: 先确保 CLI 可用，再完善 TUI

**责任人**: 开发者（dev_1）
