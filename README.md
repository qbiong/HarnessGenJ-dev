## Overview / 概述

HarnessGenJ-dev is a purpose-built AI development framework integrating three core concepts: **Adversarial Review**, **Progressive Disclosure**, and **Harness Self-Improvement**. It assembles a team of specialized AI agents — Project Manager, Architect, Developer, Code Reviewer, Bug Hunter, and Doc Writer — that collaborate to complete development tasks.

HarnessGenJ-dev 是一个专门用于软件开发的 AI 多角色协作框架，集成**对抗式审查**、**渐进式披露**和 **Harness 自我完善**三大核心理念，自动组建项目经理、架构师、开发者、审查员、Bug猎人、文档编写者团队协作完成开发任务。

### Quick Start / 快速开始

```bash
git clone https://github.com/qbiong/HarnessGenJ-dev.git
cd HarnessGenJ-dev && python bootstrap.py
# Open http://localhost:8000 → start developing / 开始开发
```
